# Demo: generic sample nation

`kosmokrator demo` builds a small synthetic fixture with the same operations an agent uses:
`create_project`, then `allocate_ids` (2 monsters, 1 site, 1 nation), then writes a generated flag TGA, then
calls `apply_mod_patch` (a single insertion checked against the inspected sha256), then `validate_mod`,
and optionally `export_mod`. There is no pre-built zip; the template lives in `kosmokrator/demo.py`.

The default project slug is `sample_mod`. The fixture has no theme or lore:

| Definition | Name | Notes |
| --- | --- | --- |
| Troop | Sample Infantry | Copies Cardaces (199) by number, including its sprite via `#copyspr` |
| Commander | Sample Commander | Copies Mystic (311) by number, including its sprite via `#copyspr` |
| Site | Sample Site | Start site |
| Nation | Sample Nation | Early Age; flag at `art/sample_flag.tga`, generated by Kosmokrator |

No vanilla sprites or other image files are redistributed; the flag and mod banner are generated
programmatically. The demo is for tooling checks only. It is not game-verified or balanced.
