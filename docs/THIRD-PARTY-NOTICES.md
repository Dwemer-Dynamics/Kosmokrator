These notices attribute dependencies and resources; they do not replace their owners' terms.

## Dominions 6

Dominions 6, its manuals, sprites and native interface graphics belong to
[Illwinter Game Design](https://www.illwinter.com/dom6/). Kosmokrator is an independent
tool. Command metadata cites the official manuals, currently indexed from version
6.36; the default project target is 6.37. This does not establish full game parity.

The command and trait indexes retain technical command names, signatures, argument
schemas, numeric constraints and manual page references. Their copied descriptive
passages were replaced with original concise help in `manual_commands_data.py` and
`traits_data.py`. Common traits have short explanations; other commands describe the
schema and point to the manual for detailed mechanics. This cleanup does not grant
rights to Illwinter's manuals or graphics, or establish comprehensive legal clearance.

The generic sample demo's vanilla sprite references name monster IDs; they do not
package the game's sprite images. Its flag and mod banner are generated by Kosmokrator
code; no image files are packaged. Vanilla reference images used during art review
remain local.

Native trait icons are extracted from each user's own `data/res.trs` into a private
workspace cache. The code and mapping metadata are supplied; the decoded game
graphics are not intended for redistribution. The extractor refuses an archive
whose hash has not been reviewed. See [TRAIT-ICONS.md](TRAIT-ICONS.md) for scope and
fallback behavior.

## dom6inspector

The optional [dom6inspector](https://github.com/larzm42/dom6inspector) catalog is a
separate GPL-3.0 project by larzm42 and its contributors. Users supply a local checkout;
Kosmokrator does not bundle or download it. Its extracted game data is a community
reference and can lag or differ from the installed game. Consult that repository's
license and notices before redistributing any of its contents.

When a user makes a project self-contained, Kosmokrator copies that checkout's tables,
its `LICENSE` and the images the project needs into the project's
`.kosmokrator/reference/` folder, with a manifest recording the origin, revision,
dataset version, licence and attribution. The images there, and any native UI icons
copied from the workspace cache, are game graphics: the snapshot is a local authoring
reference only, ignored by the project `.gitignore` and never included in exports or
Workshop folders. It is not intended for redistribution.

## Python packages and optional external tools

The core uses the Python standard library. Packaging uses setuptools; optional MCP
support uses the official [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk)
(`mcp>=1.20,<2`). Installers fetch these packages separately. Their own licenses and
transitive dependency notices remain applicable; inspect the exact installed versions
when producing a bundled runtime.

[Domerger](https://github.com/Leiriri/domerger) and
[NationGen/SpriteGen](https://github.com/elmokki/nationgen) are independently installed
optional tools. Kosmokrator supplies adapters or handoff instructions, not their code,
executables or asset libraries. Check each tool's terms before distributing its assets
or outputs. See [TOOL-INTEGRATIONS.md](TOOL-INTEGRATIONS.md).

Claude Code, Codex and image-generation services are optional authoring tools, not
embedded model dependencies. Their service terms are separate from Kosmokrator's
eventual source and asset license choices.

## Publication inventory

Review the actual archive or wheel before sharing. Exclude user projects unless
deliberately selected, `.local/`, catalog checkouts, extracted native graphics,
game archives/binaries/manual PDFs, credentials, local agent transcripts, caches and
virtual environments. Git ignore rules help with source control but do not filter
an arbitrary directory ZIP.

For a selected demo export, include only intended mod/map files, original art with
recorded provenance, installation instructions and hashes. Confirm that source,
export receipts and archive contents agree. Static validation and successful
packaging do not demonstrate game loading, balance or permission to redistribute
third-party material.
